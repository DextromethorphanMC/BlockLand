# Bliss code in BlockLand

The files that say so in their header (`bliss_clouds.glsl`, `bliss_water.glsl` and the water parts of the
lighting pack, the cloud pass) and `textures/bliss/noises.png` are ported from **Bliss v2.1.2 (Chocapic13' Shaders
edit)** by Xonk (<https://github.com/X0nk/Bliss-Shader>), an edit of **Chocapic13's shaders**
(<https://www.curseforge.com/minecraft/customization/chocapic13-shaders>). They are not BlockLand's own work; they
were adapted to BlockLand's pipeline (uniforms, passes). Bliss's own credits list follows the licence.
